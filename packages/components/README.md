# Components

City of Vernonia web components.

### About

A work in progress to replace `@vernonia/core` [widget-based](https://github.com/CityOfVernonia/core/tree/main/src/components) components with standards-based web components to be published as `@vernonia/components`.

### Timeline

No serious development is planned until [ArcGIS Maps SDK for JavaScript](https://developers.arcgis.com/javascript/latest/) version 5 and [Calcite Design System](https://developers.arcgis.com/calcite-design-system/) version 4 are released.

### Development

```shell
npm run dev
```
